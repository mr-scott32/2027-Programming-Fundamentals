# Lab 3 - Data Structures

{% hint style="info" %}
## Learning Intentions

*   Apply skills in computational thinking and programming to develop a software solution

    Including:

    * converting an algorithm into code
    * using control structures
    * using data structures
    * creating relevant subprograms that incorporate parameter passing
*   Implement data structures that support data storage

    Including:

    * single and multidimensional arrays

    * trees
    * stacks
    * hash tables

* I can develop algorithms which can loop over data structures using pseudocode.
* I can implement data structures such as lists and dictionaries in Python.
* I can manipulate data structures with for loops in Python.
* I can define all data structures that support data storage.
