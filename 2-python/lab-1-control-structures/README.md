# Lab 1 - Control Structures

{% hint style="info" %}
## Learning Intentions

* Apply computational thinking and algorithmic design by defining the key features of standard algorithms, including sequence, selection, iteration and identifying data that should be stored
* Develop structured algorithms using pseudocode and flowcharts, including the use of subprograms
*   Apply skills in computational thinking and programming to develop a software solution

    Including:

    * converting an algorithm into code
    * using control structures
{% endhint %}

{% hint style="success" %}
## Success Criteria

* I can develop algorithms with control structures (sequence, selection, iteration) using pseudocode.
* I can implement control structures using Python.
* I can apply computational thinking to solve a range of problems using control structures.
{% endhint %}

In this lab, you will learn to develop algorithms using both pseudocode and Python that respond to specific scenarios. We will be focusing on control structures - sequence, selection and iteration. In other words, we'll need to set variables and include input / output (sequence), use IF / ELSE IF / ELSE statements (selection) and use FOR / WHILE loops (iteration).&#x20;
