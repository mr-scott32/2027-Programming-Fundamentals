### Success Criteria

* I can describe processes and methodsused to plab, develop and engineer a digital version of a board game.
* I can model a simple board game using a range of modelling tools, including:
  * IPO Charts
  * Context Diagrams / Level 0 Data Flow Diagrams (DFDs)
  * Level 1 DFDs
  * Structure Charts
  * Pseudocode
  * Flowcharts
* I can develop software in Python using:
  * Control structures
  * Data structures
  * Subroutines
* I can optimise code in Python using:
  * Iteration
  * Lists
  * Dictionaries
* I can design effective software solutions to solve identified problems.
{% endhint %}
