# game.py

In `game.py` we're going to create the program. A full example is available at the back of this booklet, **but,** in this guide you're going to be given examples and will need to **apply what you learn** to **create Battleship.**

You will be provided with suggested function names and explanations, but **will need to apply yourself to make it work.**

We will build and test the functions one at a time - this is called **'decomposition',** which is idea that we break down our systems and test each element individually, rather than trying to build the whole system all at once.
