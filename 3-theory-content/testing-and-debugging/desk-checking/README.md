# Desk Checking

## Desk Checking

Desk checking is a manual process of reviewing the logic and structure of an algorithm or code by walking through it on paper or a digital document. The primary goal is to identify errors and verify the correctness of the code without executing it. During desk checking, the programmer simulates the code execution by writing down the values of variables and tracking the flow of control through loops and conditionals. This helps in understanding potential issues such as logic errors, infinite loops, and incorrect calculations before actual implementation or testing.
