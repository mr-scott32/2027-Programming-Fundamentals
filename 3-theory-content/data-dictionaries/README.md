# Introduction to Data

{% hint style="info" %}
## Learning Intention

* Investigate standard data types, including:
  * char (character) and string
  * Boolean
  * real
  * single precision floating point
  * integer
  * date and time
* Create data dictionaries as a tool to describe data and data types, structure data, and record relationships
{% endhint %}

{% hint style="success" %}
## Success Criteria

I can differentiate between data types including characters, strings, Booleans, real, single precision floating point, integer and date/time.

I can identify the main data types used in the Python programming language.

I can create data dictionaries to structure data for databases and programs.
{% endhint %}
