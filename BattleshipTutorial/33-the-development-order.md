# 33. The Development Order

When building your own version, follow this order.

Do **not** try to write the entire program at once.

### Step 1

Create and test:

```text
CreateBoard
```

### Step 2

Learn how to access positions in a 2D list.

### Step 3

Build:

```text
SetupPlayer
```

Start with one ship before adding all five.

### Step 4

Add:

```text
horizontal
vertical
```

placement.

### Step 5

Add:

```text
overlap checking
```

### Step 6

Add:

```text
repeat until valid
```

### Step 7

Use the dictionary to add all five ships.

### Step 8

Build:

```text
SetupCPU
```

using random positions.

### Step 9

Build:

```text
PlayerTurn
```

### Step 10

Build:

```text
CheckWin
```

### Step 11

Build:

```text
CPUTurn
```

### Step 12

Build:

```text
CheckLose
```

### Step 13

Build:

```text
Main
```

### Step 14

Add error handling and test the complete game.
